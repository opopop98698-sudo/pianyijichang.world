## 一、八大常见虚假宣传与套路深度拆解

```
[ 常见商家欺诈套路 ] ──────────────────────┐
  │                                        │
  ├─ 1. 文字游戏标价 ──> 标 1元/月，点进去需买三年付 ──> 强制预付沉没
  ├─ 2. 阴阳暗中扣量 ──> 节点标 1.0x，后台按 2.5x 扣费 ──> 流量神秘腰斩
  ├─ 3. 虚假千兆跑分 ──> 仅放行测速点，日常看网页卡死 ──> 刷单虚假背书
  ├─ 4. 隐蔽并发掐断 ──> 宣称不限设备，多开标签直接断 ──> 并发限流锁死
  └─ 5. 永久买断陷阱 ──> 宣称一次付费终身使用 ──────> 典型的庞氏跑路模型
```

### 1. 虚假标题标价与收银台绑售
- **套路特征**：在宣传海报或搜索引擎中打出“月付 1 元起”的吸引人标题。
- **真实现状**：用户点击进入结算后，发现 1 元只是年付 12 元折算出的单月噱头，且无法勾选单月付款；在结账时还被强制捆绑“初装技术支持费 ¥5.00”。
- **避坑法门**：非单月付款一律视为伪月付；实付款必须包含收银台所有通道杂费。

### 2. 阴阳倍率与后台暗扣量
- **套路特征**：节点列表明面上标注为 `香港 01 | 1.0x`，让用户误以为是按实际流量扣减。
- **实测抓包手段**：
  - 本地客户端抓包统计本次下载了 1.00GB 文件。
  - 登录商户后台用户中心刷新，发现用户配额被划扣了 2.50GB！
  - **原理**：运营者在后端 Shadowsocks/V2Ray 服务端配置中悄悄将上报倍率修改为 2.5x，暗中稀释套餐真实容量。

### 3. Speedtest 白名单测速欺骗
- **套路特征**：在各大测评社群发布绚丽的“全绿跑满千兆”的测速截图。
- **作弊原理**：商户在防火墙中针对 Ookla Speedtest 的机房 IP 设置了无限制 QoS 白名单，而在对一般公网 HTTP/HTTPS 请求施加 20Mbps 硬限速。跑分极为惊艳，但实际打开 YouTube 连 1080P 都频繁缓冲。
- **鉴别方法**：不要看单张跑分图，使用 Fast.com（Netflix 真实 CDN）或直接用浏览器下载 GitHub Releases 镜像包检验真实大文件吞吐。

### 4. 隐蔽的单 IP 并发连接数限制
- **套路特征**：商户主页赫然写着“不限设备数量、全家共享”。
- **暗藏枷锁**：在服务器内核参数中将单个用户的并发 TCP 连接数死死卡在 32 或 64 个。当用户打开含有多个异步请求的网页（如在线地图、代码仓库），连接池瞬间被占满，后续请求直接被服务器丢弃并重置。

## 二、长期预付与“永久套餐”的死亡概率模型

为什么商业模式决定了“终身买断”必然跑路？

$$\text{每月刚性运营成本} = \text{机房出口带宽租金} + \text{原生 IP 租金} + \text{中继专线机房开销} + \text{技术运维人力}$$

- **财务收支脱节**：
  - 正常月付模式：用户每月付费，支撑当月机房成本，现金流与成本同步匹配。
  - 终身/永久模式：用户一次性支付 99 元或 199 元，商户在首月拿走全款，但在后续的第 6 个月、第 12 个月、第 24 个月，该用户每天都在消耗真实宽带，却不再提供任何增量收入！
- **必然结局**：
  - 当新增注册用户数放缓，新资金无法覆盖老用户的带宽亏损时，商户只有两个选择：**立刻断崖式降速并关闭客服**，或者**打包用户数据库直接更名关网跑路**。

## 三、退款陷阱与霸王条款维权指引

代理行业属于非监管灰色地带，绝大多数商户的“服务协议 (TOS)”充斥着霸王条款：

1. **“售出概不退换”条款**：
   - 绝大多数商户在支付页面勾选默认条款：“虚拟商品一经激活或产生 1MB 流量，概不接受任何退款申请”。
2. **维权路径评估**：
   - **向商户发工单**：在已经无法连通的情况下，工单退款成功率通常低于 5%。
   - **支付通道争议申诉**：若使用 PayPal 或部分国际信用卡支付，可在 180 天内以“商品与描述严重不符、商家未提供约定服务”为由发起反向拒付（Chargeback）。若使用国内无退款保障的第三方代收，资金追回难度极大。
   - **最优防范**：**坚持单月低额付款！** 每次投入不超过一顿外卖钱，即使商家出现不可抗力，损失也完全在个人可承受范围内。

## 四、客户端与订阅链接安全防盗刷

1. **专有客户端木马风险 (Trojan / Backdoor)**：
   - 很多商户提供一键免配置的 `.exe` 或 `.apk` 专属安装包。
   - **风险**：此类安装包通常经过商业加壳混淆，暗中可能植入后门程序、自签伪造根证书（用于解密 HTTPS 流量）或常驻后台窃取剪贴板。
   - **安全底线**：**坚决只使用开源经过安全审计的通用客户端**（如 Clash Verge Rev、Sing-box、v2rayN、Shadowrocket），通过标准通用订阅导入节点。
2. **订阅 Token 泄露防御**：
   - 你的订阅链接形如 `https://domain.com/api/v1/client/subscribe?token=abcdef123456`。
   - 该 `token` 即为你账户的通行钥匙。若不慎在公开论坛、截图或群聊中暴露，任何人均可直接拉取你的订阅并在本地使用你的流量配额。
   - **补救措施**：一旦怀疑泄露，立即在商户后台点击“重置订阅链接 (Reset Token)”，旧链接将瞬间失效。

## 六、购买前安全自检清单与避坑 FAQ

### Q1：我怎么在购买前测试一个机场的速度？
**答**：寻找提供免费试用（如注册送 1G）或支持按月付 5–8 元极低门槛的商户。购买后，不要在早晨或中午测速，专门在**晚间 20:30 至 22:30 的极端高峰时段**进行 YouTube 4K 播放与丢包率测试。高峰期能扛住的才是真专线。

### Q2：遭遇暗扣流量怎么办？
**答**：在手机或电脑客户端中开启统计面板，连续记录三天自己实际使用的总流量；与商户后台仪表盘数据相除。如果比值严重失真（大于 1.5 倍以上），说明该商户存在隐蔽扣量行为，到期后立即拉黑换站。
