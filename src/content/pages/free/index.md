## 一、免费代理资源的三大核心类型与真实存活现状

```
[ 免费网络资源分类 ] ──────────────┐
  │                                │
  ├─ 1. 公开爬虫抓取池 ───────> 存活期 6-48 小时 ──> 极高拥堵，丢包率常年 > 50%
  ├─ 2. 商业商户注册赠额 ─────> 额度 1GB-5GB      ──> 适合验证协议连通性，不可长期依赖
  └─ 3. 广告任务赞助型 ───────> 需看广告/每日签到 ──> 耗费大量精力，晚高峰体验极差
```

### 1. 公开抓取聚合节点池 (Public Scraping Pools)
- **获取途径**：GitHub 开源订阅池、Telegram 聚合频道每日分享。
- **技术现状**：此类节点由自动化爬虫扫描全球开放代理或暴露的端口生成。由于全网数万人同时抓取，其**存活半衰期极短（通常在 6 至 48 小时内即被防火墙整体阻断或机房拔线）**。
- **体验评估**：晚高峰连通率不足 15%，TCP 握手时延常年超过 800ms，仅适合极度无聊时折腾，绝无法支撑正常工作与学习。

### 2. 商业机场新客注册赠额 (Sign-up Bonus)
- **典型规则**：注册后通过临时邮箱验证或手机号核验，系统赠送 1GB–10GB 初始配额，有效期 1 天至 3 天。
- **价值所在**：这是检验商户线路节点是否兼容自身本地宽带（电信/联通/移动）与客户端的最佳零成本方式。

### 3. 签到打卡型白嫖 (Daily Check-in)
- **典型规则**：每日登录用户面板点击签到，随机获得 100MB–1GB 额度。
- **沉没成本**：用户每天需要耗费时间登录、输入验证码，一旦连续几天忘记签到，账号可能被判定为不活跃直接回收。

## 二、免费资源的核心技术限制清单

免费资源为了防止被黑产滥用或资源耗尽，几乎无一例外设置了严格的技术枷锁：

1. **QoS 优先级垫底与带宽硬截断**：
   - 免费节点在机房调度系统中的优先级属于最低级。当付费用户流量上升时，免费节点会被系统主动实施丢包式限速（通常封顶在 2Mbps–5Mbps）。
2. **并发连接池与线程限制**：
   - 单账号限制最多同时发起 16–32 个 TCP 连接。而在现代浏览器中，打开一个包含大量图片和脚本的复杂网页就会瞬间消耗数十个并发，导致后续请求直接报错 `Connection Reset`。
3. **协议与端口封杀**：
   - 全面屏蔽 BT / P2P 下载端口，屏蔽邮件 SMTP 25 端口，且部分免费节点仅开放 HTTP 代理，不支持底层 UDP 协议，无法进行语音通话或网络联机。
4. **流媒体与 AI 工具全面屏蔽**：
   - 免费节点使用的出口 IP 几乎全部位于各大流媒体（Netflix, Disney+）与大模型平台（OpenAI, Anthropic）的高风险黑名单中，访问时 100% 弹出 `Access Denied` 或高频人机验证。

## 三、免费节点安全风险与隐私威胁模型

免费往往意味着你自身就是产品。使用不可信的公共免费节点面临以下实质性安全风险：

```
[ 你的电脑/手机 ] ──── 明文DNS / HTTP 请求 ────> [ 不可信免费中继节点 ] ────> 目标网站
                                                        │
                                            ┌───────────┴───────────┐
                                            ▼                       ▼
                                   [ 中间人嗅探窃取 ]       [ 插入恶意脚本/广告 ]
```

1. **中间人流量嗅探 (MITM Sniffing)**：
   - 若访问的网站未严格启用全站 HTTPS 或存在证书降级，节点运营者可直接截获明文传输的 Cookie、Session 凭据甚至账号密码。
2. **DNS 污染与重定向挂马**：
   - 恶意免费节点会将用户的 DNS 请求劫持至假冒的钓鱼网站或插入博彩、弹窗广告代码。
3. **连坐风控封号**：
   - 多个羊毛党共用同一出口 IP 进行垃圾邮件发送或撞库攻击，导致该 IP 下绑定的正常 Google、GitHub 或推特账号遭遇连坐封禁。
