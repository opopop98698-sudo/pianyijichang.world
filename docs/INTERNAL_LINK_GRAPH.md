# pianyijichang.world 内部链接拓扑与权重流转规范 (INTERNAL_LINK_GRAPH)

本规范定义全站内部链接（Internal Links）的层级流转、上下文语境锚文本规则与跨专题闭环逻辑，坚决防止无序全局互链造成的 PageRank 稀释和搜索机器人抓取死循环。

---

## 一、标准四层链接金字塔架构

```
                 [ 首页: / ]
                      |
    +--------+--------+--------+--------+
    |        |        |        |        |
[推荐]   [便宜]   [免费]   [性价比] ... (8个核心柱石 Pillar)
    |        |        |        |
[专题01]  [专题02]  [专题03]  [专题04] ... (64个二级专题 Topic)
    |        |        |        |
 [集群A]   [集群B]  [集群A]   [集群B] ... (128个三级集群 Cluster)
    |        |        |        |
 [文章1]   [文章2]  [文章3]   ... (384篇长尾深度文章 Article)
```

### 1. 垂直流转规则
- **首页 (`/`)**：链接到 8 个核心柱石主入口（推荐、便宜、免费、性价比、套餐、月付、对比、避坑），并放置通用预算计算与高频路径快捷入口。
- **业务柱石 (`/{pillar}/`)**：链接到属于该柱石的 8 个已发布二级专题，并在正文中推荐不超过 3 篇核心代表文章。
- **二级专题 (`/topics/{pillar}/{topic}/`)**：承接上级柱石，链接到本专题下辖的 A、B 两个集群与已发布文章，底部放置返回上级柱石的面包屑。
- **集群文章 (`/articles/{slug}/`)**：
  - 必须包含返回其所属二级专题的父级链接。
  - 必须包含本集群内部同梯队文章（文章 1 ↔ 文章 2 ↔ 文章 3）的自然语境上下文互链。
  - 结尾提供“下一步合理选购建议”（向下一层行动转化或跨专题横向求证）。

## 二、六大合规跨专题横向导航路径 (Cross-Topic Bridges)

为了满足用户真实选购决策树的延伸，全站仅允许以下 6 条经审核的跨专题语义桥梁，严禁无序全站随机互链：

1. **便宜机场 (`/cheap/`) → 流量套餐规则 (`/plans/`)**
   - **用户决策痛点**：用户在寻找超低价套餐时，容易忽视流量额度与清零机制。
   - **桥梁锚文本**：“低价购买前必须核查该档位的配额重置与结转规则”。
2. **性价比机场 (`/value/`) → 计费倍率说明 (`/avoid/multiplier-and-reset-traps/`)**
   - **用户决策痛点**：高性价比套餐往往伴随 2x、3x 的高倍率专线节点。
   - **桥梁锚文本**：“查验高倍率专线如何侵蚀名义流量配额与真实成本”。
3. **免费试用 (`/free/free-trial/`) → 首月体验验收 (`/monthly/first-month-audit/`)**
   - **用户决策痛点**：用户领取免费试用或首月特惠后，需要科学方法验收可用性。
   - **桥梁锚文本**：“按照晚高峰丢包与延时日志标准进行首月性能验收”。
4. **月付验收 (`/monthly/`) → 真实测速证据 (`/src/data/measurements.json`)**
   - **用户决策痛点**：月付用户寻找客观技术依据决定次月是否续费。
   - **桥梁锚文本**：“参考本站客观测速环境日志与晚高峰延迟基准”。
5. **价格对比 (`/compare/`) → 参与比对品牌档案 (`/src/data/brands.json`)**
   - **用户决策痛点**：用户在价格对比工具得出结论后，需要查验具体品牌的资质与客服政策。
   - **桥梁锚文本**：“查看该品牌的完整协议支持、线路架构与商业披露详情”。
6. **避坑警示 (`/avoid/`) → 条款与免责证据 (`/about/`)**
   - **用户决策痛点**：避坑页披露恶意虚假宣传与跑路风险时，需要权威中立背书。
   - **桥梁锚文本**：“查阅独立第三方评测准则与商户数据冲突核验机制”。

## 三、内部链接质量红线与自动化审计

1. **禁止死链与孤儿页**：全站所有公开静态页面深度不得超过 4 级；任何已发布的文章必须至少有 2 个正规站内入链。
2. **上下文语义锚文本**：严禁使用“点击这里”、“查看更多”等无意义锚文本，必须包含目标页面的核心意图关键词。
3. **Draft 状态隔离**：未正式发布的内容（`status: "draft"`）严禁向外链出，也不得出现在站点地图或导航菜单中。
4. **自动化把关**：通过 `npm run check` 自动执行 `scripts/check-links.mjs`，在每次部署前严密扫描站内死链与无孤儿页。
